# Reviewer walkthrough

Use a separate fresh seeded database. From the repository root, in a new PowerShell terminal:

```powershell
$env:DATABASE_URL = 'sqlite:///instance/reviewer-demo.sqlite'
$env:PORT = '5002'
.\.venv\Scripts\python.exe run.py migrate
.\.venv\Scripts\python.exe run.py seed-demo
.\.venv\Scripts\python.exe run.py serve
```

Open http://127.0.0.1:5002. Seeding refuses to overwrite populated data; use a new filename for another fresh walkthrough. Default password for the four accounts listed in README: `Demo123!`.

1. Requester: open the returned furniture request. Edit all details, reduce the sofa quantity from two to one, explain the revision, save and submit. Show that both submitted revisions remain available.
2. Approver: inspect revision 2 and approve it. Explain that editing an approved request would clear approval before any PO is issued.
3. Purchasing: choose **Upload quotation**, upload `docs/samples/quotation-fast.pdf` using PDF text. Expand the source details to inspect evidence. Map the extracted sofa price to the requested line, confirm the fields and save the quotation.
4. Record `quotation-value.pdf` as another quotation. Compare price and lead time. Choose the faster supplier with an explicit delivery rationale; issue the PO and open its printable view.
5. Receiver: use a request with quantity greater than one to demonstrate partial and final receipts. Show exactly which quantities were accepted in each delivery.
6. Explain retry protection and show the concurrency regression result. Expand **Activity & revisions** and open a submitted snapshot. Event times display WIB.

To demonstrate Gemini, replace the PDF-text upload in step 3 with the AI flow below, before issuing a PO in step 4. Stop the walkthrough server and start it in the same terminal with the hidden key prompt:

```powershell
.\tools\start-ai.ps1 -Model 'gemini-3.8-flash' -Port 5002
```

This retains the walkthrough database configured above. On the approved one-sofa request, choose **Gemini AI**, upload `docs/samples/quotation-scan.png` or `quotation-fast.pdf` and give explicit transfer consent. Verify PT Sumber Teknologi, the corresponding reference, 5 days and IDR 8,000,000. Map the line, confirm review and save. Extracting alone must not create a quotation. See [fixture values](samples/README.md). If the provider is unavailable, show the manual form and source document; do not present local-parser output as AI output.

Suggested short recording: problem and workflow (20 seconds), revision/approval (45 seconds), extraction and supplier choice (60 seconds), PO/receipt/audit (45 seconds), test and architecture evidence (30 seconds). This is a recording plan; no video has been generated by the repository.
